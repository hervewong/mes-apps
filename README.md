# Mes applications

Ce dépôt construit automatiquement :

1. **Un site** avec tous mes dépôts, chacun installable depuis Chrome (« Installer l'application »).
   Adresse : https://hervewong.github.io/mes-apps/
2. **Radio Monde pour Windows** (.exe), à télécharger dans l'onglet *Releases*.

La liste des dépôts est dans `apps.json`. Pour en ajouter un, ajoutez son nom dans la liste :
le site est reconstruit tout seul (à chaque modification et chaque jour).
